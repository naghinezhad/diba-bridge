اتصال امن سایت وردپرس به «دیباپل» (Diba Bridge) با یک کلید اختصاصی، محدودیت دسترسی و گزارش فعالیت.

== Description ==

Diba Bridge Connector افزونه‌ی همراه «دیباپل» (Diba Bridge، سرور MCP ساخت Dibachain) است. با این افزونه می‌توانید سایت وردپرس خود را از طریق دیباپل مدیریت کنید: محتوا، رسانه، سئو، ووکامرس و ابزارهای نگهداری.

**امکانات**

* کلید اتصال اختصاصی (هدر `X-Diba-Bridge-Key`)؛ فقط هش کلید ذخیره می‌شود و کلید فقط یک بار نمایش داده می‌شود.
* هر درخواست با دسترسی‌های یک کاربر وردپرس که خودتان انتخاب می‌کنید اجرا می‌شود؛ کلید هرگز از توانایی‌های آن کاربر فراتر نمی‌رود.
* روشن/خاموش کردن هر بخش به‌صورت جدا: محتوا، رسانه، کاربران، افزونه‌ها و پوسته‌ها، گزینه‌ها، ووکامرس، ابزارها.
* حالت فقط‌خواندنی، فهرست IP مجاز، سقف درخواست در دقیقه و رد اتصال روی HTTP.
* گزارش فعالیت (Audit Log) در جدول اختصاصی با پاک‌سازی خودکار روزانه.
* ابزارها: پاک‌سازی کش، جستجو و جایگزینی امن (پیش‌فرض آزمایشی)، ویرایش گروهی، کرون، حالت تعمیرات، آمار و سلامت سایت.
* سئو: Yoast SEO و Rank Math (فقط وقتی فعال باشند).
* ووکامرس: محصولات، سفارش‌ها، مشتریان، کدهای تخفیف و گزارش فروش (فقط وقتی ووکامرس فعال باشد).

**امنیت**

این افزونه هیچ مسیری برای اجرای کد PHP یا SQL دلخواه، یا خواندن و نوشتن فایل دلخواه ندارد. گزینه‌های حساس (کلیدها و saltها، فهرست افزونه‌های فعال، نقش‌های کاربری، رمزها و توکن‌ها) هرگز خوانده یا نوشته نمی‌شوند.

**مجوز**

این افزونه تحت GPL-2.0-or-later منتشر می‌شود. توجه: مخزن اصلی دیباپل مجوز MIT دارد، اما این پوشه (افزونه‌ی وردپرس) مستقل از آن و با مجوز GPL عرضه می‌شود.

== Installation ==

1. پوشه‌ی `diba-bridge-connector` را zip کنید و از «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب کنید (یا آن را در `wp-content/plugins` کپی کنید).
2. افزونه را فعال کنید.
3. به «تنظیمات ← Diba Bridge» بروید و «ساخت کلید» را بزنید. کلید را همان لحظه کپی کنید.
4. کاربر اجرای درخواست‌ها و بخش‌های مجاز را انتخاب و ذخیره کنید.
5. در دیباپل، آدرس سایت و کلید را در تنظیمات سرویس «وردپرس» وارد کنید و «تست اتصال» را بزنید.

== Frequently Asked Questions ==

= آیا سایت باید HTTPS داشته باشد؟ =

بله. درخواست‌های HTTP رد می‌شوند مگر اینکه برای توسعه‌ی محلی، گزینه‌ی «اتصال بدون HTTPS» را روشن کنید.

= اگر کلید لو برود چه کنم؟ =

در صفحه‌ی تنظیمات «باطل کردن کلید» یا «ساخت کلید جدید» را بزنید؛ کلید قبلی بلافاصله از کار می‌افتد.

= چرا بعد از تغییر saltهای وردپرس کلید کار نمی‌کند؟ =

هش کلید با salt سایت ساخته می‌شود؛ بعد از تغییر saltها یک کلید جدید بسازید.

= با حذف افزونه چه چیزهایی پاک می‌شود؟ =

تنظیمات، جدول گزارش فعالیت و کار زمان‌بندی‌شده‌ی افزونه حذف می‌شوند.
