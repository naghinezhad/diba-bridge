# Diba Bridge Connector

افزونه‌ی همراه [دیباپل (Diba Bridge)](../../README.md) برای وردپرس. با نصب این افزونه، سایت وردپرسی شما با یک کلید اختصاصی به دیباپل وصل می‌شود و دستیار هوش مصنوعی می‌تواند محتوا، رسانه، سئو، ووکامرس و ابزارهای نگهداری سایت را مدیریت کند.

## امکانات

- **کلید اتصال اختصاصی** در هدر `X-Diba-Bridge-Key`؛ فقط هش کلید ذخیره می‌شود و خود کلید فقط یک بار نمایش داده می‌شود.
- **اجرا با دسترسی یک کاربر وردپرس** که خودتان انتخاب می‌کنید؛ کلید هرگز از توانایی‌های آن کاربر فراتر نمی‌رود.
- **کلید روشن/خاموش برای هر بخش:** محتوا، رسانه، کاربران، افزونه‌ها و پوسته‌ها، گزینه‌ها، ووکامرس و ابزارها.
- **حالت فقط‌خواندنی**، فهرست IP مجاز، سقف درخواست در دقیقه و رد اتصال روی HTTP.
- **گزارش فعالیت** در جدول اختصاصی با پاک‌سازی خودکار روزانه.
- **ابزارها:** پاک‌سازی کش، جست‌وجو و جایگزینی امن (پیش‌فرض آزمایشی)، ویرایش گروهی، کرون، حالت تعمیرات، آمار و سلامت سایت.
- **سئو:** Yoast SEO و Rank Math، فقط وقتی فعال باشند.
- **ووکامرس:** محصولات، سفارش‌ها، مشتریان، کدهای تخفیف و گزارش فروش، فقط وقتی ووکامرس فعال باشد.

## نصب

1. پوشه‌ی `diba-bridge-connector` را فشرده (zip) کنید.
2. در پیشخوان وردپرس به «افزونه‌ها ← افزودن ← بارگذاری افزونه» بروید و فایل را نصب و فعال کنید.
   (یا پوشه را مستقیم در `wp-content/plugins` کپی کنید.)
3. به «تنظیمات ← Diba Bridge» بروید و «ساخت کلید» را بزنید. کلید را همان لحظه کپی کنید؛ دوباره نمایش داده نمی‌شود.
4. کاربر اجرای درخواست‌ها و بخش‌های مجاز را انتخاب و ذخیره کنید. به‌صورت پیش‌فرض فقط «محتوا» و «رسانه» روشن است.
5. در داشبورد دیباپل، نشانی سایت و کلید را در تنظیمات سرویس «وردپرس» وارد کنید و «تست اتصال» را بزنید.

## امنیت

- سایت باید HTTPS داشته باشد. درخواست HTTP رد می‌شود، مگر اینکه برای توسعه‌ی محلی گزینه‌ی «اتصال بدون HTTPS» را روشن کنید.
- افزونه هیچ مسیری برای اجرای کد PHP یا SQL دلخواه، یا خواندن و نوشتن فایل دلخواه ندارد.
- گزینه‌های حساس (کلیدها و saltها، فهرست افزونه‌های فعال، نقش‌های کاربری، رمزها و توکن‌ها) هرگز خوانده یا نوشته نمی‌شوند.
- اگر کلید لو رفت، در صفحه‌ی تنظیمات «باطل کردن کلید» یا «ساخت کلید جدید» را بزنید؛ کلید قبلی بلافاصله از کار می‌افتد.
- هش کلید با salt سایت ساخته می‌شود؛ بعد از تغییر saltهای وردپرس باید کلید جدید بسازید.
