# صرافی‌های ارز دیجیتال

دیباپل ده صرافی را با **API رسمی** خودشان وصل می‌کند: پنج صرافی ایرانی و پنج صرافی خارجی.
در داشبورد زیر **سرویس‌های مالی** دیده می‌شوند: ایرانی‌ها در `#/banking?region=iran` و
خارجی‌ها در `#/banking?region=other`.

## صرافی‌های خارجی

| صرافی | شناسه | نمونه‌ی نماد | Passphrase | مستندات رسمی |
|---|---|---|---|---|
| بایننس | `binance` | `BTCUSDT` | ندارد | <https://developers.binance.com/docs/binance-spot-api-docs/rest-api> |
| بای‌بیت | `bybit` | `BTCUSDT` | ندارد | <https://bybit-exchange.github.io/docs/v5/intro> |
| او‌کی‌ایکس (OKX) | `okx` | `BTC-USDT` | دارد | <https://www.okx.com/docs-v5/en/> |
| کوکوین | `kucoin` | `BTC-USDT` | دارد | <https://www.kucoin.com/docs/rest/> |
| کراکن | `kraken` | `XBTUSDT` | ندارد | <https://docs.kraken.com/api/> |

نماد را می‌توانید به شکل `BTC/USDT` هم بدهید؛ به قالب همان صرافی تبدیل می‌شود
(در کراکن `BTC` به `XBT` و `DOGE` به `XDG` برمی‌گردد).

## صرافی‌های ایرانی

| صرافی | شناسه | نمونه‌ی نماد | کلید | واحد قیمت بازار تومانی | مستندات رسمی |
|---|---|---|---|---|---|
| نوبیتکس | `nobitex` | `BTCIRT` | توکن، یا کلید عمومی + کلید خصوصی | **ریال** | <https://apidocs.nobitex.ir> |
| والکس | `wallex` | `BTCTMN` | فقط API Key | تومان | <https://developers.wallex.ir> |
| بیت‌پین | `bitpin` | `BTC_IRT` | API Key + Secret Key | تومان | <https://docs.bitpin.ir> |
| تبدیل | `tabdeal` | `BTCIRT` | API Key + API Secret | تومان | <https://docs.tabdeal.org> |
| آبان‌تتر | `abantether` | `BTCIRT` | فقط Api-Key | تومان | <https://docs.abantether.ir> |

نماد را می‌توانید به شکل `BTC/IRT` یا `BTC/USDT` هم بدهید. `IRT`، `TMN` و `RLS` هر سه بازار
تومانی همان صرافی را نشان می‌دهند.

نکته‌های هر صرافی:

- **نوبیتکس** قیمت بازار تومانی را به **ریال** می‌دهد و قیمت سفارش را هم به ریال می‌خواهد.
  خودِ نوبیتکس کندل‌ها را به تومان برمی‌گرداند؛ دیباپل آن‌ها را به ریال تبدیل می‌کند تا همه‌ی
  ابزارهای نوبیتکس یک واحد داشته باشند. کندل هفتگی (`1w`) ندارد. اگر فقط فیلد اول پر شود توکن
  ساده (`Authorization: Token`) فرستاده می‌شود؛ با پر کردن کلید خصوصی، هر درخواست با Ed25519
  امضا می‌شود.
- **والکس** فقط کندل‌های `1m`، `1h` و `1d` را می‌دهد.
- **بیت‌پین** و **تبدیل** کندل عمومی ندارند، پس ابزار `get_candles` برایشان ساخته نمی‌شود.
  قیمت تبدیل آمار ۲۴ساعته ندارد و از آخرین معامله و دفتر سفارش ساخته می‌شود.
- **آبان‌تتر** بازار خرید و فروش مستقیم (OTC) است: دفتر سفارش و کندل ندارد، `ask` قیمتی است
  که با آن می‌خرید و `bid` قیمتی که با آن می‌فروشید. **مقدار سفارش خرید به واحد ارز مقابل**
  (تومان یا تتر) و مقدار سفارش فروش به واحد خودِ رمزارز است.

داده‌ی عمومی هر پنج صرافی ایرانی با API واقعی آزمایش شده است. موجودی و ثبت سفارش بر اساس
مستندات رسمی هر صرافی نوشته و با سرور آزمایشی تست شده، ولی با حساب واقعی امتحان نشده است؛
پیش از تکیه بر آن، با یک کلید فقط‌خواندنی «تست اتصال» را بزنید.

## ابزارها

هر صرافی تا هفت ابزار دارد (به‌جای `<id>` شناسه‌ی صرافی را بگذارید). ابزاری که صرافی
پشتیبانی نمی‌کند ساخته نمی‌شود:

| ابزار | کار | نیاز |
|---|---|---|
| `<id>_get_ticker` | آخرین قیمت، بهترین خرید و فروش، بیشینه و کمینه و حجم ۲۴ساعته | هیچ |
| `<id>_get_orderbook` | دفتر سفارش تا ۵۰ سطح از هر طرف | هیچ |
| `<id>_get_candles` | کندل‌های `1m`، `5m`، `15m`، `1h`، `4h`، `1d`، `1w` از قدیم به جدید | هیچ |
| `<id>_get_balances` | موجودی دارایی‌های غیرصفر | کلید API |
| `<id>_get_open_orders` | سفارش‌های باز | کلید API |
| `<id>_place_order` | ثبت سفارش spot از نوع `market` یا `limit` | کلید API + اجازه‌ی معامله |
| `<id>_cancel_order` | لغو یک سفارش باز | کلید API + اجازه‌ی معامله |

خروجی‌ها در همه‌ی صرافی‌ها یک شکل دارند. تفاوت‌ها:

- **درصد تغییر ۲۴ساعته** (`changePercent24h`) برای کراکن برگردانده نمی‌شود، چون
  این صرافی فقط قیمت بازِ امروز (UTC) را می‌دهد، نه قیمت ۲۴ ساعت پیش.
- **موجودی بای‌بیت** از حساب `UNIFIED` و **موجودی کوکوین** از حساب `trade` خوانده می‌شود.
- **مقدار سفارش** به واحد ارز پایه است (مثلاً BTC در BTC/USDT)، حتی برای خرید market.
  تنها استثنا خرید در آبان‌تتر است که به واحد ارز مقابل ثبت می‌شود.

## اتصال

1. در داشبورد صرافی را روشن کنید. داده‌ی بازار از همین لحظه کار می‌کند.
2. برای موجودی و سفارش‌ها در خودِ صرافی یک کلید API بسازید و **فقط دسترسی خواندن** بدهید.
3. `API Key` و `API Secret` (و برای OKX و کوکوین `Passphrase`) را در فرم همان صرافی ذخیره کنید.
   والکس و آبان‌تتر فقط یک کلید دارند.
4. «تست اتصال» را بزنید: اول داده‌ی بازار و بعد خواندن موجودی با کلید شما آزمایش می‌شود.

همین مقادیر را می‌شود با متغیر محیطی هم داد، مثلاً برای بایننس:

```dotenv
BINANCE_ENABLED=true
BINANCE_API_KEY=...
BINANCE_API_SECRET=...
BINANCE_ALLOW_TRADING=false
```

## ایمنی معامله

- **معامله پیش‌فرض خاموش است.** تا وقتی «اجازه‌ی معامله» (`allowTrading`) روشن نشود،
  `place_order` و `cancel_order` با پیام روشن رد می‌شوند.
- **بدون تأیید چیزی فرستاده نمی‌شود.** `place_order` بدون `confirm=true` فقط پیش‌نمایش
  سفارش را برمی‌گرداند. کلاینت هوش مصنوعی باید پیش‌نمایش را به کاربر نشان بدهد و پس از
  تأیید او دوباره با `confirm=true` فراخوانی کند.
- **دسترسی برداشت (Withdraw) را هرگز به کلید ندهید.** دیباپل هیچ ابزاری برای برداشت ندارد
  و به این دسترسی نیاز ندارد.
- در صورت امکان کلید را به **IP همین سرور** محدود کنید.
- کلید و رمز API مثل بقیه‌ی تنظیمات در `data/config.json` با دسترسی محدود ذخیره می‌شوند و
  در پاسخ‌ها و پیام‌های خطا پنهان می‌مانند.
- هر سفارش با **پول واقعی** شما ثبت می‌شود و خروجی مدل‌های هوش مصنوعی ممکن است نادرست باشد.
  مسئولیت معامله‌ها با خود شماست؛ بخش «مسئولیت امنیتی و استفاده‌ی تجاری» در README را بخوانید.

## دسترسی شبکه

بعضی صرافی‌ها از بعضی کشورها در دسترس نیستند و بعضی صرافی‌های ایرانی فقط با IP ایران جواب
می‌دهند. اگر «تست اتصال» خطای شبکه داد، از
**تنظیمات ← فهرست پروکسی** یک یا چند پروکسی ثبت کنید و انتخاب خودکار را روشن کنید.
رعایت شرایط استفاده‌ی هر صرافی و قوانین کشور شما بر عهده‌ی خودتان است.

## افزودن صرافی تازه

هر صرافی فقط یک adapter است (نشانی‌ها و امضای خودش) و بقیه‌ی کار را
`defineExchange` در [`src/providers/exchanges/common.ts`](../src/providers/exchanges/common.ts)
انجام می‌دهد. یکی از فایل‌های همان پوشه را الگو بگیرید، adapter را در
[`src/providers/index.ts`](../src/providers/index.ts) ثبت کنید و برای امضا و شکل درخواست‌ها
در [`test/unit/exchanges.test.ts`](../test/unit/exchanges.test.ts) یا
[`test/unit/exchanges-iran.test.ts`](../test/unit/exchanges-iran.test.ts) تست بنویسید.
متدهای `orderBook`، `candles`، `openOrders` و `cancelOrder` اختیاری‌اند؛ اگر صرافی یکی را
ندارد، ننویسیدش.
